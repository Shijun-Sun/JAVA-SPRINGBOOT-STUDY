## 阶段 2：Spring Boot 3.x 核心

**目标**：掌握 Spring Boot 3.x（基于 Spring 6），这是当前主流版本

### 2.1 基础核心

- **自动配置原理**：`@SpringBootApplication`、`@ConditionalOn*`、`AutoConfiguration.imports`
- **依赖注入**：`@Component`、`@Service`、`@Repository`、构造器注入（推荐）
- **配置管理**：`application.yml`、`@ConfigurationProperties`、多环境 Profile
- **Spring AOT**（Spring 6 新特性）：提前编译优化，为 GraalVM 原生镜像做准备

> 跳过：XML Bean 配置、`web.xml`、applicationContext.xml

### 2.2 REST API 开发

- `@RestController`、`@RequestMapping`、参数绑定
- **Bean Validation**：`@Valid`、`@Validated`、自定义约束
- **全局异常处理**：`@RestControllerAdvice`、`ProblemDetail`（RFC 7807，Spring 6 原生支持）
- **API 文档**：SpringDoc OpenAPI 3（替代 Swagger 2 / SpringFox，后者已停止维护）

### 2.3 响应式（了解即可）

- **Spring WebFlux**：了解响应式模型，知道何时选择它
- 大型传统应用优先用 Spring MVC + Virtual Threads，WebFlux 适合特定场景

## 阶段 3：数据层现代方案

**目标**：掌握现代 ORM 和数据访问方式，彻底告别手写 JDBC

### 3.1 主流方案对比

| 方案 | 定位 | 推荐场景 |
|------|------|---------|
| **Spring Data JPA + Hibernate 6** | 全功能 ORM | 复杂领域模型、关系映射丰富 |
| **MyBatis-Plus** | 半 ORM，SQL 可控 | 国内大型项目主流，SQL 调优需求强 |
| **Spring Data JDBC** | 轻量 ORM | 简单数据模型，拒绝 JPA 复杂性 |
| **JOOQ** | 类型安全 SQL DSL | SQL 复杂、追求编译期检查 |

**建议学习顺序**：Spring Data JPA → MyBatis-Plus（国内大型项目基本都用）

> 跳过：原始 JDBC Template 作为主要方案、Hibernate 3/4 旧 API

### 3.2 Spring Data JPA 核心

- **Repository 接口**：`JpaRepository`、方法名查询、`@Query`
- **事务管理**：`@Transactional`、传播行为、隔离级别
- **实体映射**：`@Entity`、`@OneToMany`、懒加载 vs 立即加载
- **Specification**：动态查询构建
- **Projections**：DTO 投影，避免 N+1

### 3.3 数据库迁移

- **Flyway** 或 **Liquibase**（大型项目必备，版本化管理 schema 变更）
- 不要依赖 `spring.jpa.hibernate.ddl-auto=update`（生产禁用）

### 3.4 缓存

- **Spring Cache 抽象** + **Redis**（Lettuce 客户端）
- **Spring Data Redis**、序列化方案（Jackson2JsonRedisSerializer）

## 阶段 4：安全体系

**目标**：掌握现代 Spring Security 6，实现企业级认证授权

### 4.1 Spring Security 6（Spring Boot 3.x 内置）

> 注意：Spring Security 6 API 大幅重构，旧版教程（`WebSecurityConfigurerAdapter`）已废弃，不要学

- **新 API 风格**：基于 `SecurityFilterChain` Bean 配置
- **认证流程**：`UsernamePasswordAuthenticationToken`、`UserDetailsService`
- **授权**：`@PreAuthorize`、方法级安全

### 4.2 JWT + OAuth2（主流方案）

- **JWT 认证**：Spring Security + `spring-security-oauth2-resource-server`
- **OAuth2 / OIDC**：`spring-boot-starter-oauth2-client`、集成 KeyCloak / Okta
- **JWT 最佳实践**：Refresh Token、Token 吊销策略

> 跳过：Session-based 认证（大型分布式应用不适用）、旧版 OAuth2 配置方式

### 文档资源

**Spring Security 6**
- [Spring Security 官方文档](https://docs.spring.io/spring-security/reference/) — 最权威，必读（英文）
- [Spring Security Architecture 概览](https://spring.io/guides/topicals/spring-security-architecture/) — 官方架构说明，理解过滤器链必读（英文）

## 阶段 5：大型应用架构实践

**目标**：掌握大型 Java Web 应用的核心工程实践

### 5.1 分层架构与 DDD

- **标准分层**：Controller → Service → Repository（严格单向依赖）
- **DDD 轻量实践**：领域对象 vs DTO 分离、防腐层
- **六边形架构**（了解）：端口与适配器模式

### 5.2 消息队列

- **RocketMQ** 或 **Kafka**（大型应用异步解耦必备）
- Spring for Apache Kafka / RocketMQ Spring Boot Starter
- 核心概念：生产者/消费者、消息可靠性、幂等性

### 5.3 微服务基础（可选，视团队架构而定）

> 注意：不是所有大型应用都是微服务，单体模块化同样是主流选择

- **Spring Cloud 2023.x**（对应 Spring Boot 3.x）
- 服务注册发现：**Nacos**（国内主流）或 Eureka
- 配置中心：**Nacos Config** 或 Spring Cloud Config
- 网关：**Spring Cloud Gateway**（替代 Zuul，后者已停止维护）
- 负载均衡：Spring Cloud LoadBalancer（替代 Ribbon，后者已停止维护）
- 熔断限流：**Sentinel**（替代 Hystrix，后者已停止维护）
- 服务调用：**OpenFeign**

> 跳过：Zuul、Ribbon、Hystrix（均已停止维护）

### 5.4 可观测性

- **Spring Boot Actuator**：健康检查、指标端点
- **Micrometer + Prometheus + Grafana**：指标监控
- **OpenTelemetry**：分布式链路追踪（替代老版 Sleuth + Zipkin）
- **结构化日志**：Logback + JSON 格式，便于 ELK 采集

### 5.5 测试策略

- **单元测试**：JUnit 5、Mockito
- **集成测试**：`@SpringBootTest`、`@DataJpaTest`、Testcontainers（真实数据库）
- **API 测试**：MockMvc、RestAssured

## 阶段 6：云原生与部署

**目标**：掌握现代化部署方式

### 6.1 容器化

- **Docker**：编写 Dockerfile、多阶段构建优化镜像大小
- **Docker Compose**：本地开发环境编排
- **Jib**（推荐）：Maven/Gradle 插件，无需 Dockerfile 直接构建 Java 镜像

- Pod、Deployment、Service、Ingress、ConfigMap、Secret

### 6.3 GraalVM 原生镜像（了解）

- Spring Boot 3.x 原生支持 GraalVM Native Image
- 编译时间长，但启动极快，适合 Serverless 场景

### 6.4 CI/CD

- **GitHub Actions** 或 **Jenkins**：自动化构建、测试、部署
- Maven / Gradle 构建工具（Maven 更主流，Gradle 更灵活）
