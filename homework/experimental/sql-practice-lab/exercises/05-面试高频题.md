# 练习 05 · 面试高频题（M02 第 1~4 章综合）

> **形式**：一半是**口述概念**（面试官问、你答），一半是**现场写 SQL**。
> **用法**：先合上讲义，自己口头/书面答一遍，再对照讲义查漏。想让我扮演面试官连环追问，说 `压力测试我 训练营05`。
> **答案政策**：默认不直接给答案；要标准答案说 `直接给标准答案 训练营 05-题N`。

> 这些是国内后端面试真实高频问法，按"能不能讲清原理 + 能不能落到 SQL"考察。

---

## A. 建模与类型（对应 01 章）

1. 电商为什么要拆 SPU 和 SKU？各自存什么？价格库存放哪层、为什么？
2. 金额字段为什么不能用 `float`/`double`？用什么？对应 Java 什么类型？
3. 主键为什么推荐 `BIGINT` 自增？自增主键对 InnoDB 有什么好处？什么场景改用分布式 ID（雪花）？
4. `DATETIME` 和 `TIMESTAMP` 区别？各自的坑（范围、时区、2038）？
5. 为什么互联网项目常用**逻辑外键**不用物理外键？物理外键的代价是什么？
6. 分类树有哪几种建模（邻接表/路径枚举/闭包表）？邻接表查所有后代怎么写？

## B. InnoDB 与索引（对应 02、03 章）⭐ 重灾区

7. 聚簇索引和二级索引的区别？叶子节点分别存什么？
8. 什么是"回表"？怎么避免？什么是"覆盖索引"？`EXPLAIN` 哪个标志代表覆盖？
9. 为什么 InnoDB 用 B+ 树而不是 B 树/红黑树/哈希？（结合磁盘 IO、范围查询、树高）
10. 联合索引 `(a,b,c)`，`WHERE b=? AND c=?` 能走吗？为什么？——**最左前缀**说清楚。
11. `WHERE a=? AND b>? AND c=?` 用到了哪几列？`c` 为什么用不上定位？
12. 索引失效的常见场景说 5 个，并各给一个能走索引的改写。
13. 为什么不建议给"性别/状态/是否删除"这类列单独建索引？"选择性"是什么？
14. `Using index` 和 `Using index condition` 有什么区别？ICP 解决什么问题？
15. 联合索引 `(a,b,c)` 能不能同时服务 `WHERE a`、`WHERE a,b`、`WHERE a,b,c`？（最左前缀复用）

## C. EXPLAIN 与优化（对应 04 章）⭐

16. `EXPLAIN` 的 `type` 从好到坏排一遍。`ALL` 和 `index` 分别意味着什么？
17. `key_len` 有什么用？给一个联合索引和一条 SQL，你能算出用到了第几列吗？
18. `Using filesort` 是什么意思？怎么消除？
19. `SELECT * FROM t ORDER BY id LIMIT 1000000, 10` 为什么慢？写出两种优化方式并说清各自限制。
20. 一条线上 SQL 突然变慢，SQL 没改、索引没动，可能是什么原因？（统计信息、数据量增长、缓存失效、锁等待……）
21. 慢查询日志怎么开？怎么从一堆慢日志里找到"最该优化的那条"？（按总耗时聚合）
22. 你优化一条慢 SQL 的完整流程（SOP）是什么？为什么每步都要"前后对比"？

## D. 现场写 SQL（用 explain 或 basic 数据都行）

23. 写出"每个分类下上架商品数量，只显示数量 ≥ 100 的分类，按数量倒序"。（GROUP BY + HAVING + ORDER BY）
24. 写出"查询每个 SPU 的最低价 SKU 的 sku_code 和 price"。（分组取每组极值行，想想怎么避免只取到 MIN(price) 却拿错 sku_code）
25. 给"某分类下、上架、按创建时间倒序、分页取第 N 页"设计索引 + 写出高效分页 SQL（结合键集分页）。
26. 写一条会触发 `Using filesort` 的查询，再改写成不触发的。
27. `category` 表用递归 CTE 查"某个一级分类下的所有子孙分类 id"。

## E. 架构追问（区分"会用"和"懂取舍"）

28. 一张表 1000 万行，一条走了索引的查询还是慢，除了索引你还会从哪些角度优化？（SQL 改写、缓存、归档、分区、分库分表、读写分离）
29. 索引不是越多越好，为什么？写多读少的表加索引要注意什么？
30. 覆盖索引"空间换时间"的边界在哪？什么时候加宽索引不划算？
31. 高并发 + 大数据量下，深分页（如"跳到第 5000 页"）产品和技术上分别怎么处理？

## 自测方式

- 每题先**限时口述**（概念题 1 分钟内、SQL 题 5 分钟内），模拟面试压力。
- 写 SQL 的题都在库里真跑一遍，确认结果对。
- 答不利索的题标记出来，回对应章节讲义复习；想要连环追问就喊 `压力测试我 训练营05`。
