# Java 语法 AI 指导文件

> 目标：把 Java 基础语法拆成独立章节文件，每个文件包含“知识讲解区 + 练习留空区 + AI review 规则”。

---

## 1. 文件组织方式

建议按章节命名：

- `base1.java`：基础语法第一章：变量、类型、运算符
- `base2.java`：基础语法第二章：流程控制、数组、方法
- `base3.java`：基础语法第三章：面向对象
- `base4.java`：基础语法第四章：集合与泛型
- `base5.java`：基础语法第五章：异常与 IO
- `base6.java`：基础语法第六章：并发基础
- `base7.java`：基础语法第七章：注解与反射
- `java9.java`：Java 9 新特性
- `java10.java`：Java 10 新特性
- `java11.java`：Java 11 新特性
- `java17.java`：Java 17 新特性
- `java21.java`：Java 21 新特性

---

## 2. 统一文件结构

每个章节文件都建议分为三段：

### 2.1 知识讲解区
- 用注释写清楚章节重点
- 每个知识点尽量短句、条目化
- 可以放少量示例代码帮助理解

### 2.2 练习留空区
- 只保留题目、要求、参考知识点
- 先不写答案
- 使用 `TODO` 占位，方便后续自己完成

### 2.3 AI review 区
- 说明你希望 AI 如何检查
- 建议包含：语法、思路、风格、边界条件、是否符合题意

---

## 3. review 规则

当你写完一个章节的练习后，可以这样让我 review：

### 3.1 你可以直接发给我
- 整个文件
- 某一题的代码
- 你认为有问题的片段

### 3.2 我会优先检查
1. 语法是否正确
2. 题意是否完成
3. 类型使用是否合理
4. 是否有更简洁的写法
5. 是否存在基础概念错误

### 3.3 你可以指定 review 模式
- `只指出错误，不直接给答案`
- `先解释问题，再给改进建议`
- `直接给标准答案`
- `按初学者角度讲解`

---

## 4. 推荐学习节奏

1. 先看章节讲解区
2. 自己完成练习留空区
3. 发给 AI review
4. 根据反馈改一版
5. 再进入下一章
