> **编号 00**：它横跨 01~04、并会随后续章节持续追加练习，放最前当"常驻训练场"。
> **落位**：实验脚手架在 `homework/experimental/sql-practice-lab/`（可反复重置，不属正式交付、不阻塞推进）。

## 三、怎么用（推荐节奏）

1. **先过一遍对应章节讲义**（01~04 学习目录），再来练；
2. 按脚手架 `exercises/` 里 **01 → 06 的顺序**刷；
3. 每题**先自己写、自己在库里跑**，对照"期望结果"自测；卡住看"提示"；
4. 想让我批改：贴你的 SQL + 结果，说 `Review 训练营 0X-题N`；
5. 想要面试连环追问：`压力测试我 训练营05`；
6. 确实要标准答案：`直接给标准答案 训练营 0X-题N`（主动触发的例外）。

> **答案政策**：按仓库教学规则，练习默认只给题目 + 提示 + 期望结果，**不直接给答案 SQL**——SQL 是练出来的。你 SQL 基础偏弱，所以这里的**讲解**会比别的章更细（语法逐段拆、坑逐个点），但成品答案仍默认留给你写。

## 五、完成标准（自评）

这章没有"验收门禁"（它是实验区训练，不阻塞推进），但建议练到：

- [ ] 基础查询（JOIN、GROUP BY、子查询）能不看提示独立写出；
- [ ] 给一条 SQL，能预判它的 `type`/走不走索引，再用 `EXPLAIN` 验证；
- [ ] 会算 `key_len`、能解释最左前缀走到第几列；
- [ ] 能讲清并手写深分页的两种优化；
- [ ] 面试题（练习 05）B、C 两组能顺畅口述；
- [ ] 六大类坑（练习 06）都亲手复现过、知道怎么避。

练到这个程度，M02 前四章的理论就真正长在手上了，后面第 10 章把 `product-service` 落到 MySQL 时会轻松很多。
