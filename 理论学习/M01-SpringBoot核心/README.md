## 一、模块目标（学完要能做到）

原理层面：
- 说清 Spring Boot 相比当年 `Spring MVC + web.xml` 到底省掉了什么、代价是什么
- 说清应用启动的完整链路，能在任意环节插入自己的逻辑
- 说清自动配置的生效与失效机制，能独立排查"为什么这个 Bean 没被注入"
- 说清 IoC 容器的价值 —— 为什么大型项目离不开它

工程层面：
- 搭出一个能长期演进的分层骨架，边界清晰（Entity / DTO / VO 不混用）
- 写出规范的 REST API：统一响应、参数校验、全局异常、链路日志
- 会写单元测试和集成测试，不靠"启动服务点一下"验证
