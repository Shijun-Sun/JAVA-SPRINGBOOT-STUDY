### start.spring.io 的使用

> 来源问题：start.spring.io 的使用展开讲讲

#### 两种主要使用方式

**方式一：浏览器界面**

打开 [https://start.spring.io](https://start.spring.io)，关键字段说明：

| 字段 | 说明 | 建议 |
|------|------|------|
| Project | 构建工具 | Maven（主流企业项目） |
| Spring Boot | Boot 版本 | 选最新稳定版，带 `(M*)` 的是里程碑版不选 |
| Group | Maven groupId | 倒写的域名，如 `com.study.mall` |
| Artifact | artifactId + 项目文件夹名 | `product-service` |
| Package name | 根包名，**影响启动类位置和 ComponentScan 范围** | `com.study.mall.product` |
| Packaging | 打包类型 | Jar（内嵌容器，容器化友好） |
| Java | JDK 版本 | 17+（Boot 4 强制要求） |

**方式二：curl 命令行**

```bash
# 先查可用版本，别靠记忆
curl https://start.spring.io/metadata/client | python3 -m json.tool | grep -A 20 '"bootVersion"'

# 生成项目
curl https://start.spring.io/starter.zip \
  -d type=maven-project \
  -d language=java \
  -d bootVersion=4.0.4 \
  -d javaVersion=17 \
  -d groupId=com.study.mall \
  -d artifactId=product-service \
  -d packageName=com.study.mall.product \
  -d dependencies=web,validation,actuator \
  -o product-service.zip
```

**依赖 ID 查询：**

```bash
curl https://start.spring.io/metadata/client | python3 -m json.tool | grep '"id"' | head -50
```

**方式三：IntelliJ IDEA 集成**

`File → New Project → Spring Initializr`，背后调用接口和网页完全一样。

#### 常用依赖速查

| 依赖 ID | 作用 |
|---------|------|
| `web` | Spring MVC + 内嵌 Tomcat，写 HTTP 接口必须有 |
| `validation` | JSR-303 参数校验（`@NotNull`、`@Size` 等） |
| `actuator` | 健康检查、监控端点 |
| `data-jpa` | Spring Data JPA + Hibernate |
| `mysql` | MySQL 驱动 |
| `h2` | 内存数据库，练习时不想装 MySQL 用这个 |
| `lombok` | 减少 getter/setter 样板代码 |
| `devtools` | 热重载，改代码不用重启 |
| `security` | Spring Security，**加了之后所有接口默认需要认证** |

---

#### 容易踩的坑

- **加了 `security`**：所有端点自动要认证，浏览器打开 localhost:8080 会跳登录页，控制台会打出随机密码
- **加了 `h2` + `data-jpa` 但又配了连不通的 MySQL datasource**：启动直接失败
- **原则**：只加现在明确需要用的依赖，后面随时可以往 pom.xml 里加，不要"先全选以备用"
